How the model was selected

Five-fold cross-validation compares ridge regression settings with a mean baseline. Scaling is fitted inside each training fold. The test set is used only after selection.

The saved model uses only the training partition. Cross-validation variation and average test error are not individual confidence intervals. Download held-out predictions.

About the data. Historical mathematics records from two Portuguese schools. This model requires both earlier grades and is not an enrollment-time prediction. Questionnaire timing should be verified for prospective use. Results need local validation before use in another school; associations do not establish causal effects.
